## 阶段二：硬件选型与采购 (1周)

### 2.1 机架选择
**推荐入门配置**：
- **机架类型**：450mm 四旋翼机架 (最经典、配件多)
  - 品牌：Q450、S500 或类似克隆版
  - 材质：玻纤或碳纤维
  - 价格：¥50-200

### 2.2 动力系统 (4套)
| 部件 | 推荐配置 | 价格 |
|------|---------|------|
| 电机 | 2212 KV980 | ¥30-60 /个 |
| 电调 (ESC) | 30A (支持OneShot) | ¥30-80 /个 |
| 螺旋桨 | 1045 或 9443 (2正2反) | ¥5-20 /对 |

### 2.3 飞控
**推荐**：
- **入门级**：F450 + Pixhawk 1M / Pixracer
- **经济型**：F4 Flight Controller (Betaflight)
- **价格**：¥200-800

### 2.4 遥控器
- **推荐**：富斯 i6X (6通道) 或 乐迪 AT9S
- **价格**：¥200-500
- **注意**：需要买对应接收机

### 2.5 电池
- **规格**：3S LiPo (11.1V) 2200-3000mAh 25C
- **品牌**：格氏 (ACE)、花牌
- **价格**：¥80-200
- **必备**：平衡充电器 (B6AC 或类似)

### 2.6 其他配件
- GPS模块 (可选但推荐)
- 电源模块 (PMU)
- 蜂鸣器、安全开关
- 扎带、双面胶、螺丝工具等

### 2.7 完整清单 (参考)
```

电机 x4 (2212 KV980) ¥160
电调 x4 (30A)         ¥160
螺旋桨 x2套         ¥30

遥控器 + 接收机      ¥300
电池 3S 2200mAh     ¥100
充电器               ¥150
GPS + 指南针         ¥100
杂项 (线、扎带等)    ¥50
--------------------------

```

## 阶段四：组装 (1周)

### 4.1 机架组装
- [ ] 阅读机架说明书
- [ ] 安装机臂
- [ ] 固定电机座

### 4.2 动力安装
- [ ] 电机安装 (注意转向！)
  - 电机1/3：顺时针 (CW)
  - 电机2/4：逆时针 (CCW)
- [ ] 电调固定
- [ ] 焊接电源分配板 (Power Distribution Board)

### 4.3 飞控安装
- [ ] 飞控固定 (建议用减震棉)
- [ ] 电调信号线连接 (按顺序！)
- [ ] GPS/指南针安装 (远离干扰)
- [ ] 电源模块连接

### 4.4 接线检查清单
- [ ] 正负极未接反 (重中之重！)
- [ ] 电调信号线顺序正确
- [ ] 所有焊点牢固
- [ ] GPS方向箭头朝前
- [ ] 飞控箭头朝机头方向

**⚠️ 安全警告**：
- 第一次上电前务必反复检查！
- 卸下螺旋桨再进行测试！
- 准备灭火器/沙子 nearby

## 阶段五：地面站配置与校准 (1周)

### 5.1 飞控连接
- [ ] 安装地面站软件 (QGroundControl / Mission Planner)
- [ ] USB连接飞控
- [ ] 检查传感器数据

### 5.2 校准流程 (按顺序!)
1. **加速度计校准** - 按提示放六个面
2. **指南针校准** - 画8字
3. **遥控器校准** - 每个通道的最大最小值
4. **电调校准** - 设置油门行程 (重要!)

### 5.3 飞行模式设置
- [ ] 设至少3个模式：Stabilize, AltHold, PosHold
- [ ] 设置故障保护 (Failsafe)

### 5.4 电机测试
```
⚠️ 再次警告：卸下螺旋桨！
```
- [ ] 用地面站测试每个电机顺序
- [ ] 检查旋转方向是否正确

## 常见问题

### Q: 第一次预算不够怎么办？
A:
1. 买二手件 (注意检查好坏)
2. 先买遥控器 (以后可以一直用)
3. 选择更小的机架 (250mm 更便宜)

### Q: 在哪里买配件？
A:
- 淘宝/天猫 (最方便)
- 立创商城 (电子元件)
- 二手市场 (闲鱼)

### Q: 没人教怎么办？
A:
- B站视频非常多！
- 加入当地的航模俱乐部
- 很多模友很愿意带新手
