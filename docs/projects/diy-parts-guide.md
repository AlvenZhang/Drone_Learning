# 无人机配件DIY指南：哪些可以自己做？

想自己动手做配件？这很酷！我们来看一下哪些可以做。

---

## 🟢 强烈推荐自己做的

### 1. 机架 ✅✅✅ 最推荐！

#### 为什么推荐自己做？
- 结构简单，就是几根板子/杆子
- 可以用常见材料
- 成就感超强！
- 坏了自己修很方便

#### 方案A：3D打印机架
```
需要：
- 3D打印机 (或者去淘宝打印)
- CAD软件 (Fusion 360 / SolidWorks / FreeCAD)
- PLA/ABS耗材

优点：
- 想设计成什么样就什么样
- 精度好
- 重量轻

成本：
- 自己打印：¥50-100 (耗材钱)
- 淘宝打印：¥100-200

参考：
- 网上搜 "Q450 3D打印图纸"
- 很多开源的！
```

#### 方案B：手工机架 (玻纤板/木板/碳纤板)
```
材料：
- 玻纤板/环氧板 (万能的淘宝)
- 薄木板 (也可以用)
- 碳纤维板 (贵一点，但是好)

工具：
- 钢锯/线锯
- 什锦锉刀
- 手电钻
- 游标卡尺 (可选但推荐)

步骤：
1. 找图纸 (网上搜 Q450 尺寸)
2. 打印出来贴在板子上
3. 按线切割
4. 打孔
5. 组装！

成本：
- 玻纤板：¥30-50
- 工具：如果没有，¥100左右一套 (以后能用)

优点：
- 超级有成就感！
- 材料好找
- 尺寸灵活
```

#### 方案C：甚至用筷子+KT板！
```
真的可以！我见过！
- 机臂：烧烤用的竹签/筷子
- 中心板：KT板/硬纸板
- 用热熔胶粘+线绑
- 可以飞！

成本：
- 几乎0成本！

适合：
- 练手
- 先做个迷你的试试水
```

---

### 2. 电源分配板 (PDB) ✅

#### 为什么可以自己做？
- 就是把电池正极连到4个电调正极
- 负极同理
- 很简单！

#### 方案A：洞洞板 + 导线
```
材料：
- 洞洞板 (万能板)
- 粗导线 (18AWG或更粗)
- 焊锡

步骤：
1. 正极都焊一起
2. 负极都焊一起
3. 分别接电池正负极

成本：¥10-20
```

#### 方案B：PCB打样
```
- 用 KiCad 画个简单的板子
- 嘉立创打样：5片约 ¥50
- 更专业！

成本：¥50-80
```

---

### 3. 减震板/脚垫 ✅

#### 可以自己做的东西
- 飞控减震垫
- 相机减震 (如果装航拍)

#### 材料
- 3D打印
- 或者用海绵、硅胶板剪一剪
- 甚至用羽毛球拍的减震条！

---

### 4. 螺旋桨 (实验性质) ⚠️

#### 可以，但不推荐飞行用
- 可以用3D打印
- 可以用玻纤板切
- 但是！动平衡很难做！

#### 建议
- 可以做几个玩玩
- 真要飞还是买现成的桨
- 便宜又安全

---

## 🟡 可以尝试做，但有点难的

### 1. 电调 (ESC) ⚠️

#### 难度：中高
- 主要是MOS管驱动
- 还有控制电路
- 体积要做小有点难

#### 可以试试的方案
- 买现成的电调PCB空板
- 自己焊元件
- 或者用开源项目 (比如BLHeli)

#### 建议
- 新手别从这个开始
- 先买现成的用
- 以后有兴趣再研究

---

### 2. 飞控 ⚠️ 我们之前讨论过的

#### 难度：中
- 可以用Arduino/STM32自己做
- 但是要写很多代码

#### 建议
- 先买现成的飞
- 等有兴趣了再自己做

---

### 3. 遥控器接收机 ⚠️

#### 难度：高
- 射频部分不好搞
- 还要对频
- 法律问题 (2.4G需要认证)

#### 建议
- **直接买！别自己做！**
- 安全第一！

---

## 🔴 强烈建议买现成的

### 1. 电机 ❌ 别自己做！

#### 为什么？
- 需要绕线机绕漆包线
- 充磁机充磁
- 动平衡调试
- 这些设备普通人没有

#### 而且
- 买现成的很便宜
- 2212电机才¥30-40一个
- 做得还比我们好

---

### 2. 电池 ❌ 绝对别自己做！

#### ⚠️ 非常危险！
- LiPo电池自己做很容易短路起火
- 需要专门的保护电路
- 还要平衡充电

#### 建议
- **直接买品牌电池！**
- 安全第一！

---

### 3. 电调 ❌ 新手别自己做

#### 理由
- 买现成的才¥30一个
- 自己做花的时间精力不值得
- 做坏了容易烧电机/飞控

---

### 4. 螺旋桨 (真飞的话) ❌

#### 理由
- 动平衡很重要！
- 自己做的可能震动很大
- 影响飞行甚至炸机
- 现成的才¥5-10元一对
