## 省钱秘诀大公开

### 1. 遥控器 - 可以一直用的！
- **强烈建议买新的**！
- 富斯i6X 全新约 ¥200-250
- 你以后换飞机还能用这个遥控
- 二手遥控信号不稳会炸机！

### 2. 哪里买二手最便宜？
- **闲鱼**：搜索关键词
  - "四旋翼 拆机"
  - "无人机 退模"
  - "F3飞控"
- **5iMX 论坛交易区**
- **模友群**：退魔老司机白送都有可能！

### 3. 机架/电机/电调 - 可以二手
- 这些耐艹，一般坏不了
- 注意检查电机轴承是否顺滑
- 电调不发烫就没事

### 4. 飞控 - 建议买新的
- 二手有可能有暗病
- 新的 F4 飞控也就 ¥150
- 省心！

### 5. 电池 - 小心二手
- 二手电池可能鼓包/怀孕
- 寿命不清楚
- 建议买新的！

## 再省一点的技巧

### 1. 先买个迷你小四轴练手 (¥100-200)
- 先买现成的玩具四轴
- 练习手感，不炸钱
- 熟练了再自己做

### 2. 用手机当显示
- 很多飞控支持手机连接
- 先用手机调参

### 3. 工具可以借/共用
- 电烙铁万用表找朋友借

### 4. 闲鱼蹲守"退魔"
- 经常有人整架出，很便宜
