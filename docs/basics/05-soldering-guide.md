# 无人机焊接完全指南

第一次焊无人机？别怕，其实很简单！

---

## 📍 哪些地方需要焊接？

### 1. 电源分配板 (PDB) ⭐ 最常见的！

#### 方案A：自己做PDB
```
需要焊：
- 电池正极 → PDB正极焊盘
- 电池负极 → PDB负极焊盘
- 4个电调正极 → 分别焊到PDB正极
- 4个电调负极 → 分别焊到PDB负极

焊点数：1 + 1 + 4 + 4 = 10个点
```

#### 方案B：买现成的PDB
```
可能需要焊：
- 电调的电源线焊到PDB上
- 或者用插座，但焊接更可靠

焊点数：4-8个点
```

---

### 2. 电调延长线 (可选但常用)

#### 为什么要延长？
- 电调自带的线可能不够长
- 或者想换更粗的线

#### 焊接点
- 电调原来的线剪断
- 接上新的延长线
- 每个电调3根线 (红/黑/信号)
- 4个电调 = 12个焊点

---

### 3. 电调 → 电机连接

#### 两种方式
```
方式1：直接焊
- 把电机三根线直接焊到电调三根线
- 优点：可靠
- 缺点：拆电机麻烦
- 焊点数：4个电机 × 3 = 12个点

方式2：用3.5mm香蕉头 (推荐！)
- 电机线焊香蕉头公头
- 电调线焊香蕉头母头
- 优点：方便更换电机/电调
- 焊点数：4个电机 × 3 × 2 = 24个点 (但是方便！)
```

---

### 4. 飞控的焊点 (取决于飞控)

#### 有些飞控板
- 可能需要焊插针
- 或者焊电容
- 但是很多成品飞控不需要焊

---

### 5. LED灯条 (可选)

#### 想装LED
- LED正极焊到飞控5V或电池正极
- LED负极焊到飞控或电池负极
- LED信号线焊到飞控LED引脚

## 📝 焊接步骤详解

### 步骤0：安全准备
```
⚠️ 重要！
1. 找个通风的地方
2. 旁边放一杯水/湿纸巾
3. 烙铁不用时放支架上
4. 别碰烙铁头！
5. 烙铁用完记得断电
```

---

### 步骤1：准备工作
```
1. 电烙铁通电预热
2. 焊锡丝和助焊剂准备好
3. 要焊的线剥好头：
   - 剥掉3-5mm的绝缘皮
   - 露出里面的铜丝
   - 拧一下，不要散开
```

---

### 步骤2：给线上锡
```
这步很重要！叫做"预上锡"
1. 烙铁头沾一点松香
2. 烙铁头靠在铜丝上加热
3. 同时把焊锡丝靠上去
4. 焊锡会融化，均匀地覆盖铜丝
5. 每根线都这样先上一遍锡

为什么要预上锡？
- 焊接更可靠
- 不容易虚焊
```

---

### 步骤3：给焊盘上锡
```
如果是PDB或PCB板的焊盘
1. 烙铁头沾松香
2. 烙铁头靠在焊盘上
3. 焊锡丝靠上去
4. 焊盘会镀上一层光亮的锡
```

---

### 步骤4：焊接在一起
```
1. 把预上锡的线靠在焊盘上
2. 烙铁头同时加热线和焊盘
3. 焊锡丝靠上去一点点
4. 看到焊锡融化，均匀覆盖
5. 保持1-2秒
6. 移开烙铁
7. 等它冷却，别碰它！

成功的焊点：
- 光滑、发亮
- 像小馒头形状
- 没有毛刺
```

---

### 步骤5：绝缘！
```
这步绝对不能省！
焊好之后：
- 用热缩管套住焊点
- 用打火机/热风枪加热
- 热缩管会收缩，紧紧包住
- 或者用电工胶布缠起来

为什么要绝缘？
- 防止短路！
- 万一碰到其他焊点就炸了！
```

---

## ✅ 焊点检查清单

焊完每一个点都检查：
- [ ] 焊点光亮，不是暗淡的
- [ ] 没有虚焊 (轻轻拉一下，不动)
- [ ] 没有毛刺
- [ ] 焊锡量适中，不是太多也不是太少
- [ ] 没有短路 (相邻的焊盘没有连在一起)
- [ ] 已经做好绝缘了

## ⚠️ 常见问题

### 问题1：焊锡不粘？
```
原因：
- 线或焊盘没上锡
- 烙铁温度不够
- 氧化了

解决：
- 先预上锡！
- 烙铁头清理干净
- 用点助焊剂
```

### 问题2：虚焊？
```
症状：看起来焊上了，但是一拉就掉
原因：
- 加热时间不够
- 焊锡没完全融化

解决：
- 重新焊，烙铁多停留一会儿
- 确保焊锡完全融化
```

### 问题3：烙铁头变黑？
```
解决：
- 用高温海绵擦
- 或者在湿抹布上蹭
- 或者重新上锡
```

### 问题4：焊太多连在一起了？
```
解决：
- 用吸锡器吸掉多余的
- 或者用吸锡线
- 小心一点，慢慢来
```

## 🎯 焊接练习建议

### 第一次焊无人机前，先练习
```
建议先拿废线/废电路板练
1. 练给线上锡
2. 练两个线焊在一起
3. 练焊到洞洞板上
4. 觉得有把握了再焊真飞机！
```

## 📊 完整焊接工作量估算

### 入门套装 (Q450 + 现成PDB)
```
PDB:
- 电池正负极焊到PDB：2个点
- 4个电调电源焊到PDB：8个点
合计：10个点

电机-电调连接 (用香蕉头)：
- 4个电机 × 3根 × 2头 = 24个点
合计：24个点

总焊点：约 34个点
```

### 进阶套装 (自己做PDB)
```
会多几个焊点，但差不了太多
```
