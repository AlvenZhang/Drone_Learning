## 1. 电机

### 电机长什么样？
- 圆盘状，有底座，有轴
- 一般有3根线 (A/B/C)

### 核心参数

#### KV值 (最重要！)
```
含义：每增加1V电压，电机空转转速增加的值
单位：RPM/V (转每分钟/伏)

举例：
- 2212 KV980：加11.1V (3S)，空转约 980×11.1 ≈ 10878 RPM
- 2212 KV2300：同样11.1V，空转约 2300×11.1 ≈ 25530 RPM

选型原则：
✅ 大桨 → 低KV (推荐 KV900-1100)
✅ 小桨 → 高KV (KV2000-2600)
```

**为什么？**
- 低KV电机扭力大，带得动大桨
- 高KV电机转速快，配小桨

#### 尺寸型号 (2212, 2312...)
```
22  12
↑   ↑
定子直径 定子高度 (单位：毫米)

举例：
- 2212：定子直径22mm，高度12mm
- 2312：稍微大一点点，力更大一点

选型原则：
✅ 250机架 → 1806 / 2204
✅ 330/450机架 → 2212 / 2312
✅ 550+机架 → 3508 / 更大
```

#### 其他参数
- **最大电流**：短时间能承受的电流 (一般10-20A)
- **重量**：越轻越好，但要够力
- **轴承数**：双轴承比单轴承好

### 电机接线
```
电机线颜色随机，不一定对应！
方法：任意接，如果反转，任意交换两根线
```

### 电机转向 (非常重要！)
```
四旋翼布局 (X形)：

    前
    M2 (CCW) ↙ ↗ M1 (CW)
       \    /
        \  /
         --
        /  \
       /    \
    M4 (CW) ↖ ↘ M3 (CCW)

CW = Clockwise = 顺时针
CCW = Counter-Clockwise = 逆时针

怎么判断？
- 不装桨，轻轻推油门，看转向
- 不对就调线
```

### 推荐品牌
- **朗宇 (SunnySky)**：品质好，价格适中
- **新西达 (XXD)**：便宜，入门够用
- **致盈 (T-Motor)**：高端，专业
- **银燕 (EMAX)**：穿越机常用

## 2. 电调 (ESC)

### 电调是干嘛的？
- 全称：Electronic Speed Controller
- 作用：把电池的直流电变成电机需要的三相电
- **相当于电机的"油门"**

### 电调长什么样？
- 小方块
- 一边两根粗线 (接电池)
- 一边三根细线 (接电机)
- 还有一组信号线 (接飞控)

### 核心参数

#### 持续电流
```
含义：长时间工作能承受的最大电流
单位：安培 (A)

举例：
- 20A电调：持续20A没问题
- 30A电调：持续30A没问题

选型原则：
✅ 留余量！电机最大电流10A → 选20A电调
✅ 2212电机 + 1045桨 → 20A-30A电调足够
```

#### 瞬时电流
```
含义：短时间能承受的最大电流
一般比持续电流大30%-50%
```

#### 支持电压
```
看支持多少S的电池：
- 2S (7.4V)
- 3S (11.1V)
- 4S (14.8V)
- 6S (22.2V)

选型原则：
✅ 跟电池匹配
✅ 3S电池 → 选支持2-3S或2-4S的电调
```

#### 协议 (BLHeli, OneShot, DShot...)
```
这个说的是电调跟飞控的通信方式
- 普通 PWM：老式的，也能用
- OneShot125：比PWM快
- DShot：数字信号，抗干扰好 (推荐)

入门选：支持DShot的电调
```

#### BEC (重要！)
```
含义：Battery Elimination Circuit = 降压供电电路
作用：给飞控和舵机供电 (不用额外加电池)

参数：
- 输出电压：5V / 6V / 可调
- 输出电流：1A / 2A / 3A...

选型原则：
✅ 一定要有BEC！除非你是专业配置
✅ 2A BEC足够一般设备
```

### 电调连接
```
电池 +- <-> 电调粗线
电调三根细线 <-> 电机三根线
电调信号线 (红/棕/橙) <-> 飞控

注意：
- 红 = 正极
- 黑/棕 = 负极 (GND)
- 橙/黄/白 = 信号线
```

### 电调校准
```
为什么要校准？
让电调知道遥控器的最大最小油门位置

步骤：
1. 遥控器油门推到最高
2. 上电
3. 听到滴滴两声后，油门拉到最低
4. 听到滴一声，完成！
```

### 推荐品牌
- **好盈 (HobbyWing)**：FlyFun系列，经典
- **中特威 (ZTW)**：性价比高
- **银燕 (EMAX)**：穿越机常用
- **便宜杂牌**：入门能用，但小心炸机

## 3. 螺旋桨

### 桨的规格 (1045, 6045...)
```
10  45
↑   ↑
桨直径 螺距 (单位：英寸)

什么是螺距？
→ 想象桨是螺丝，旋转一圈前进的距离
```

#### 桨直径
```
单位：英寸，1英寸 = 2.54厘米

常见规格：
- 5030 (5寸)：迷你四轴
- 6045 (6寸)：250穿越机
- 8045 (8寸)：330机架
- 1045 (10寸)：450机架
- 1240 (12寸)：550+大机架
```

#### 螺距
```
螺距大 = 同样转速下拉力大，但耗电快
螺距小 = 温柔一点，续航好一点

入门选：中等螺距 (40-50)
```

### 正反桨 (重要！)
```
每架飞机需要：2正 + 2反

怎么区分？
- 正桨 (R)：字母R，或旋转方向顺时针
- 反桨 (L)：字母L，或旋转方向逆时针

或者看桨叶：
- 看凸起朝哪个方向
- 对照说明书！
```

### 材质
| 材质 | 优点 | 缺点 | 价格 |
|------|------|------|------|
| 塑料 (ABS) | 便宜、安全 | 容易断 | 便宜 |
| 尼龙玻纤 | 强度好 | 贵一点 | 中等 |
| 碳纤维 | 轻、硬、性能好 | 贵、打伤人很痛 | 贵 |

**入门推荐**：普通塑料或尼龙玻纤桨

### 桨的安装
```
⚠️ 重要！
1. 看清正反
2. 对准电机轴
3. 螺丝拧紧但不要滑丝
4. 桨要装平，不要歪

检查方法：
- 用手转一下，看晃不晃
- 晃就是没装好
```

### 什么时候换桨？
- 炸机后
- 有裂纹
- 缺角
- 平衡不好 (震动大)

## 4. 电池

### 电池类型
- **LiPo (锂聚合物)**：现在99%用这个
- 镍氢：老式的，不用看了

### 核心参数

#### S数 (串联数)
```
S = Series = 串联

电压：
- 1S = 3.7V (单节标称电压)
- 2S = 7.4V
- 3S = 11.1V (最常用！)
- 4S = 14.8V
- 6S = 22.2V

满电电压：
- 1S = 4.2V
- 3S = 12.6V

低压报警：
- 单节3.5V左右要降落
- 不要低于3.2V！

选型原则：
✅ 250/330/450机架 → 3S
✅ 大机架/长续航 → 4S/6S
```

#### 容量 (mAh)
```
含义：电池能存多少电
单位：毫安时 (mAh)

举例：
- 1500mAh：以1.5A放电能放1小时
- 2200mAh：以2.2A放电能放1小时

关系：
✅ 容量大 = 续航长 = 重量大 = 价格贵

选型参考：
- 250机架：800-1300mAh
- 330/450：1500-2200mAh
- 大机架：3000-6000mAh
```

#### C数 (放电倍率)
```
含义：电池能放出多大电流
计算：最大放电电流 = 容量 × C数 / 1000

举例：
- 2200mAh 25C → 2.2 × 25 = 55A 最大放电
- 1500mAh 45C → 1.5 × 45 = 67.5A 最大放电

选型原则：
✅ 动力够用就行，太大浪费钱
✅ 入门：20C-30C足够
✅ 暴力飞行：45C+
```

### 电池接口
常见类型：
- **XT60**：大电流首选 (推荐！)
- **XT30**：小电流用
- **JST**：小电池用
- **T插**：老式的，容易打火

**入门推荐**：XT60

### 电池使用注意事项
```
⚠️ LiPo电池很娇贵！
1. 不要过充过放 (电压低于3.2V要充电)
2. 不要穿刺、短路
3. 不要摔
4. 充电时有人照看
5. 不用时存放在防火袋里
6. 电压保持在3.8V左右长期存放

充电注意：
- 必须用平衡充！
- 选对S数！
```

### 电池品牌
- **格氏 (ACE)**：性能好，价格合理 (推荐)
- **花牌 (HobbyKing)**：性价比高
- **富力**：不错
- **杂牌**：小心虚标！

## 5. 飞控

### 飞控是干嘛的？
- 无人机的"大脑"
- 读传感器 → 算姿态 → 发指令给电调

### 飞控组成
一般集成：
- **陀螺仪**：测角速度
- **加速度计**：测加速度
- **气压计**：测高度
- **磁力计** (指南针)：测方向
- (可选) **GPS**：定位

### 常见飞控型号

#### 入门级
| 型号 | 价格 | 特点 |
|------|------|------|
| CC3D | ¥50-80 | 简单、开源 |
| F3 | ¥80-150 | 升级版、常用 |
| F4 | ¥150-250 | 性能好、推荐 |

#### 进阶级
| 型号 | 价格 | 特点 |
|------|------|------|
| Pixhawk 1M | ¥300-500 | 经典、开源、功能全 |
| Pixracer | ¥400-600 | 小、强大 |
| Omnibus F4/F7 | ¥150-300 | 穿越机常用 |

#### 飞控软件/固件
- **Betaflight**：穿越机首选 (简单)
- **Cleanflight**：老一点，也能用
- **PX4**：专业、功能强、稍复杂
- **ArduPilot**：专业、功能全

**入门推荐**：先玩 Betaflight 或 PX4

### 飞控安装
```
重要！
1. 箭头朝机头方向
2. 水平安装
3. 用减震棉 (减少震动)
4. 远离电机干扰
```

### 飞控校准 (很重要！)
```
每次装机必须做的校准：

1. 加速度计校准
   - 按提示放六个面
   - 放稳等提示音

2. 指南针校准
   - 拿飞机在空间画8字
   - 或者绕圈慢慢转

3. 遥控器校准
   - 每个通道推到最大最小
   - 记录中点

4. 电调校准
   - 前面讲过的
```

## 6. 遥控器

### 遥控器参数

#### 通道数
```
最少需要4通道：
1. 油门
2. 俯仰
3. 横滚
4. 偏航

实际推荐：6-8通道
→ 可以切换飞行模式、开开关等

常见规格：
- 4通道：入门玩具
- 6通道：入门无人机 (够用)
- 8-16通道：高级功能
```

#### 遥控距离
- **玩具级**：几十米
- **入门级**：1-2公里
- **专业级**：5-20公里

#### 2.4G 频段
现在基本都是2.4G
- 抗干扰好
- 省电
- 距离够

#### FHSS / DSSS
- 跳频扩频 / 直序扩频
- 都是抗干扰技术
- 不用太纠结，一般都够用

### 常见遥控器

#### 入门级 (推荐)
| 型号 | 价格 | 通道数 | 特点 |
|------|------|--------|------|
| 富斯i6X | ¥200-250 | 6-10 | 性价比之王！ |
| 乐迪AT9S | ¥300-400 | 9-12 | 功能多 |
| 富斯i6 | ¥150-200 | 6 | 经典便宜 |

#### 专业级
- **Futaba**：贵、稳、专业
- **JR**：同样高端
- **FrSky**：开源爱好者常用

### 遥控器模式 (油门在哪边？)
```
美国手 (Mode 2)：
- 左手：油门 + 偏航
- 右手：俯仰 + 横滚
→ 最常用！推荐新手选这个

日本手 (Mode 1)：
- 左手：俯仰 + 偏航
- 右手：油门 + 横滚
```

### 遥控器使用
```
1. 对频：让遥控器和接收机配对
2. 开关检查：每个开关对应哪个通道
3. 舵量检查：看数据对不对
4. 失控保护设置：很重要！
```

## 7. 机架

### 机架尺寸
```
指两个对角电机的距离，单位毫米

常见尺寸：
- 250mm：迷你穿越机
- 330mm：小型四轴
- 450mm：经典入门尺寸 (最推荐！)
- 550mm+：大载重/长续航
```

### 机架材质
| 材质 | 优点 | 缺点 | 价格 |
|------|------|------|------|
| 塑料 | 便宜、安全摔不伤人 | 软、易断 | 最便宜 |
| 玻纤 (G10/FR4) | 强度好、耐炸 | 重一点 | 中等 |
| 碳纤维 (CF) | 轻、硬、好 | 贵、摔了心疼 | 贵 |

**入门推荐**：玻纤或塑料机架

### 常见机架型号
- **Q450**：最经典！
- **S500**：比Q450大一点
- **F330**：小一点，便宜
- **QAV250**：穿越机用

### 机架组装要点
```
1. 看说明书！别装反机臂
2. 螺丝不要拧太用力 (滑丝就哭了)
3. 电机座要上紧
4. 脚架要稳
```
