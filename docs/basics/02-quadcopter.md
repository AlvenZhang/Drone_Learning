# 四旋翼无人机基础

## 四旋翼结构

四旋翼无人机有四个电机，通常排列成X形或+形：

```
    1      2
     \    /
      \  /
       --
      /  \
     /    \
    4      3
```

电机1和3顺时针旋转，电机2和4逆时针旋转（或反之）。

## 飞行控制原理

通过调整四个电机的转速来实现不同的飞行动作：

- **悬停**：所有电机转速相同
- **上升/下降**：同时增加/减小所有电机转速
- **俯仰（前后）**：增加后方电机转速，减小前方电机转速（或反之）
- **横滚（左右）**：增加右侧电机转速，减小左侧电机转速（或反之）
- **偏航（旋转）**：增加顺时针电机转速，减小逆时针电机转速（或反之）

## 传感器

典型的四旋翼配备：
- IMU（惯性测量单元）：加速度计 + 陀螺仪
- GPS/北斗：定位
- 气压计：高度测量
- 磁力计：方向测量
