# 坐标系和运动学

## 常用坐标系

### 1. 机体坐标系（Body Frame）
- 原点：无人机质心
- X轴：指向机头
- Y轴：指向右翼
- Z轴：指向下方（右手坐标系）

### 2. 地面坐标系（World Frame / NED）
- N：North - 北向
- E：East - 东向
- D：Down - 向下

### 3. ENU坐标系
- E：East - 东向
- N：North - 北向
- U：Up - 向上

## 欧拉角

描述无人机姿态的三个角度：

1. **Roll（横滚角）**：绕X轴旋转
2. **Pitch（俯仰角）**：绕Y轴旋转
3. **Yaw（偏航角）**：绕Z轴旋转

## 四元数

欧拉角存在万向锁问题，实际工程中常用四元数表示姿态。
